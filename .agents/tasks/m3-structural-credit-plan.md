## Design decisions (made from the existing code; one or two sentences each)

- **Reuse, do not rebuild.** `app/schemas/bo_m3.py::M3CorporateAssessment` ALREADY carries `legal_entities`, `ownership_relationships`, `cash_flow_locations`, `cash_transfer_relationships`, `structural_credit_findings`, `management_assessments`, `governance_screening`, `information_gaps`. The M3 prompt (`app/prompts/bo_prompts.py` `_SPECIALIST_INSTRUCTIONS["M3"]`) already covers dimensions A–F narratively. So Layer 2 is NOT new schema scaffolding — it is (1) fixing the ordering so the specialist actually SEES the validated structure, (2) a small additive provenance-linkage field set on `StructuralCreditFinding`, (3) Validator 7 cross-checks against the admitted structure graph, (4) prompt reinforcement of the evidence standards + simulation safeguard, (5) output distinction of deterministic observations vs AI findings, (6) tests + demo. This is the smallest coherent change set.

- **One specialist, one validator.** No new agent. `m3_corporate_management` + `validate_m3_assessment` (Validator 7) are reused. The deterministic `_derive_structural_signals()` in `app/services/bo/corporate_structure.py` stays the sole source of factual structural observations; the LLM only proposes `structural_credit_findings` (credit INTERPRETATIONS) that REFERENCE those facts by stable id.

- **Additive, versioned, backward compatible.** New schema fields on `StructuralCreditFinding` default to empty/neutral so existing scripted proposals (e.g. in `tests/integration/test_bo_m3_standalone.py`, `test_bo_v3_complete.py`) still validate. No enum is invented; reuse `Direction`, `Materiality`, `Confidence`, `Admissibility`, `Disposition`, `ClaimType` from `app/schemas/bo.py` / `app/schemas/agentic.py`. Bump `M3_ASSESSMENT_VERSION`/`M3_VALIDATOR_VERSION` additively (see item 2).

- **Structure-in-context representation.** A compact, provenance-preserving dict (`structural_facts`) is built from the validated `CorporateStructureArtifact` (nodes+links+borrower+ownership%+guarantor flags+grouping classifications+source doc id/hash+simulation status+stable node/link ids) and injected into `_single_pass_inputs` BEFORE `run_single_pass`. The specialist reads it; it is DATA, never an instruction, and the specialist may not rewrite it.
